# Ceylan Hair Design görselleri

Bu klasöre site için kullanılacak gerçek görselleri yükleyebilirsin.

Önerilen dosyalar:
- `logo.png` — Ceylan Hair Design logosu
- `hero.jpg` — ana sayfa büyük görseli
- `about.jpg` — hakkımızda görseli
- `gallery-01.jpg` ... `gallery-08.jpg` — galeri görselleri

En iyi sonuç için JPG/PNG kullan. Telefonundan Instagram'dan kaydettiğin görselleri buraya yükleyebilirsin.

Dosyaları yükledikten sonra bana **"görselleri ekledim"** yaz; site kodundaki geçici görselleri bu klasördeki gerçek görsellerle değiştireceğim.
